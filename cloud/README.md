# Cloudflare 实验版

本目录包含网站、实时连接和充电历史服务。页面沿用 Mac 版的界面；ESP32 通过加密 WebSocket 连接，浏览器通过密码登录。当前实现仍需真实充电器、断网及重启测试，不能作为安全断电保护。

## 本地测试

在本目录运行 `npm ci`、`npm test` 和 `npm run dry-run`。`npm run dev` 启动本地服务；测试和构建前会从原有网页生成被忽略的 `public/` 文件。不要把真实密码或设备凭据写入源码、测试数据或 Git。

## 部署概要

使用 Cloudflare Workers 和 SQLite Durable Objects，先创建 Worker，再通过 Cloudflare Secret 配置 `VIEWER_PASSWORD`、`SESSION_SECRET` 和 `DEVICE_TOKEN`，并绑定自己的自定义域名。三个值应分别随机生成且保密；域名和设备配置应保存在被忽略的本地文件中。`workers_dev` 默认关闭。生产部署前应检查账户计划、免费额度和自定义域名，避免覆盖已有站点。

ESP32 的配置、配网安全和当前限制见 [固件说明](../src/cuktech-ble-ha-main/esp32_ble/CLOUD.md)。历史数据受 Cloudflare 存储与写入额度约束；多设备及长时间运行前请观察实际用量。网关掉电会丢失尚未上传的缓存。

## 每个用户首次安装

每个人使用自己的米家账号、Cloudflare 账号和域名部署一份独立实例。当前不是在作者网站上开放注册的公共服务；下载项目不会获得作者的设备或账号权限。

1. 在项目根目录按主 README 安装 Mac 环境，然后初始化自己的子域名：

   ```sh
   .venv/bin/python macos/cloud_init.py charge.example.com
   ```

   将示例替换为自己的完整子域名。此命令只创建本机配置，不会修改 DNS 或收费。它会生成网站密码、设备上传凭据和会话密钥，保存在被 Git 忽略的 `runtime/` 中。重复执行会拒绝覆盖，避免换一次安装就让已配置设备失效。

2. 首次部署云端服务：

   ```sh
   cd cloud
   npm ci
   npx wrangler login
   npm test
   npm run dry-run
   npx wrangler deploy
   npx wrangler secret bulk ../runtime/cloudflare-secrets.json
   ```

   登录自己的 Cloudflare 账号，确认 `cuktech-live` 名称没有与已有项目冲突。默认关闭公共 workers.dev 地址，配置秘密后在 Cloudflare 控制台的该 Worker 设置中添加自己的自定义域名。以后重新部署时也要确认自定义域名仍然绑定。免费计划有额度限制，不保证无限制免费。

3. 按固件说明编译并刷写适合自己开发板的固件。先识别芯片、备份闪存；本项目当前验证的构建目标是 ESP32-S3，不能将此目标直接用于所有 ESP32 型号。

4. 在项目根目录运行 `bash macos/manage.sh run`，另开一个终端运行 `.venv/bin/python macos/esp_setup.py`。在助手中点击 **扫码登录米家**，直接显示二维码；用自己的米家 App 扫码并确认。程序自动获取设备列表，选择充电器并导入，密钥自动获取和保存，无需用户寻找、复制或粘贴。

5. 返回配网助手检查导入结果，将 Mac 连接到开发板配网热点。随机热点密码由 USB 串口显示；填写自己要供 ESP32 使用的 2.4 GHz Wi-Fi 名称和密码，点击发送。助手从本机配置取出设备凭据并发送给 ESP32，不把米家账号登录会话上传到 Cloudflare。请确认充电器作为 Mac 配置中的主设备。首次真实连接尚需观察认证结果。

6. 配置成功后停止 Mac 本地服务，避免它与 ESP32 同时连接充电器。ESP32 独立通电并联网后，使用 `runtime/网站登录密码.txt` 中的密码访问自己的网站。

## 日常使用与重新配置

ESP32 将 Wi-Fi、设备凭据和云端连接配置写入非易失存储，普通断电重启会读取已有配置。日常查看只需打开网站，不必运行 Mac 助手、扫码或重新配网。网站登录会话目前有效期为 12 小时；过期后重新输入网站密码即可，不需要重新获取米家密钥。

换 Wi-Fi、换充电器、撤销设备凭据、清空闪存或恢复出厂后才需要对应的重新配置。当前云端模式关闭了局域网配置接口，尚没有完善的实体按键恢复配网流程；重新配网前应保留本机配置并按固件维护方式处理，不能假定网页里已有一键换网。更换或重置充电器可能使旧密钥失效，届时重新扫码。

不要把 `runtime/`、闪存备份、扫码会话或日志打包进开源发布包。初始化工具不会读取或复用作者的配置。米家账号只用于首次获取设备凭据；网站密码是另一份独立生成的凭据。
