## 验证与限制

本机最终验证：Python 主项目与 macOS/发布检查共 **918 项通过**；HA 测试替身 **308 项通过**；**13 组**前端 JavaScript 脚本通过。Shell 语法、双架构启动器构建与 codesign 验证通过；当前本机安装的 **32 个依赖**经 pip-audit 检查，未发现已知漏洞。发布检查对提交索引和工作区的 335 个公开文件扫描，0 项命中；检查包含 gzip 内容与禁用的本地运行产物。

代码审查、模式扫描和自动测试不等同于安全认证，也不能证明不存在所有问题。真实米家扫码、充电器连接和端口控制、Intel 实机、ESP32 烧录、真实 HA 实例尚需另行验证。运行数据已清空，之后启动服务需要重新导入设备。

可选 ESP32 固件仍存在公开默认配网密码、无认证 Web 界面和部分明文云/MQTT 通信，仅用于可信网络；未来远程版本必须另行实现 TLS 和设备授权。本地服务不会因为本次发布自动具备远程访问能力。
