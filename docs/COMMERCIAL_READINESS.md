# 正式版准备情况

本文记录当前代码可验证的事实与正式对外提供服务前仍需完成的工作，不表示已经通过商业发布、硬件安全或法律审查。

## 当前范围

- ESP32-S3 通过蓝牙读取支持的充电器，通过 Wi-Fi 和云端展示数据；实际可用功能取决于充电器型号、固件和网络。
- 单位为充电器输出侧的 Wh；它不是设备电池实际存储的能量。
- 网关重启后已恢复的能量限额会暂停，必须重新设置。自动关闭依赖采样、蓝牙连接和网关运行，不应作为安全保护装置。
- 网关断网时缓存有容量限制；断电会丢失未上传的记录。曲线原始数据默认保留 30 天，不能据此承诺无限历史。
- 面向开源使用者的云端方案是每人独立部署和配置，并非已有的多租户公共服务。

## 发布前仍需完成

1. **硬件与网络验收**：在目标充电器型号和固件上覆盖冷启动、断电、Wi-Fi 和云端中断、蓝牙占用、长时间运行、自动限额暂停与恢复；记录复现条件和结果。模拟测试不能替代实体设备验收。
2. **第三方素材与协议**：项目代码的许可证及来源见 [第三方来源与许可](../THIRD_PARTY_NOTICES.md)。其中产品图片等素材的独立授权尚未确认；商业发布前应取得相应授权或替换为有明确许可的素材，并确认所使用的第三方服务和接口适用于计划中的发布方式。
3. **可用性与成本**：依据目标设备数和采样频率测量 Cloudflare 的请求、存储、数据库读写和费用；明确容量、恢复目标、备份和异常告警，不能假定免费额度可支撑商业流量。
4. **交付与维护**：完成跨浏览器及真实 iOS/Android 设备测试，建立版本发布、回滚、升级和用户支持流程；验证用户换网、换设备和恢复配网的步骤。
5. **自动化与发布门槛**：持续运行 Python、网页和云端回归；建立 ESP32 固件构建和硬件回归记录。任何自动断电能力的描述应与验证范围一致。
