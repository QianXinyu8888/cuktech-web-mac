# ESP32 远程实时查看实现计划

**目标：** 保留Mac版，新增ESP32独立采集、Cloudflare安全转发和实时网页。
**架构：** 见 ../specs/2026-11-07-esp32-cloud-design.md，协议字段与认证边界以该规格为准。
**技术栈：** ESP-IDF 5.3、esp_websocket_client、Cloudflare Workers/Durable Objects、原生JS、Node测试。

## 全局约束

只有遥测白名单上云；设备与网页使用不同凭据；TLS不能关闭验证。硬件刷写前先备份。不把个人数据写入源码/日志。网页仅显示真实数据；默认v1不持久保存历史、不开放远程控制。云端运行时不使用周期定时器阻止休眠。

## 任务1：云端协调服务

- [ ] 创建 cloud/package.json、wrangler.jsonc、src/worker.js、src/room.js、src/protocol.js、test/。
- [ ] 先写 node --test 用例验证 telemetry白名单、Origin、签名cookie和期满、连接角色、重连替换与rate协调；观察实现缺失失败。
- [ ] 实现Worker入口、独立设备Bearer Token、网页登录与签名Cookie、DO Hibernation。绑定 ASSETS 与 ROOM，SQLite migration new_sqlite_classes。
- [ ] 运行 npm test、wrangler deploy --dry-run，测试身份隔离与休眠attachment恢复；报告真实测试结果。

## 任务2：ESP32固件

- [ ] 修改config_store.h/c与HTTP本地配置，增加cloud_url/cloud_token/cloud_enabled，读回token脱敏且保存掩码不覆盖原值。
- [ ] 创建cloud_bridge.c/h，独立任务快照（含valid），WSS TLS/SNTP、rate消息/断线重连、每秒/30秒节流；添加managed component依赖。
- [ ] 修复S3编译配置/并发cJSON池等集成问题，生成嵌入资源并在实际ESP-IDF工具链编译S3。
- [ ] 本地合成快照/配置验证，报告构建结果；不自行刷写或记录真实密钥。

## 任务3：网页、集成和部署

- [ ] 创建cloud/public/index.html与配套CSS/JS，沿用现有产品风格；密码登录、四端口卡片、近期曲线、连接/过期提示、重连与退出。
- [ ] 本地wrangler+模拟设备在真实浏览器验证输入数据导致卡片与曲线变化、掉线提示、手机宽度布局、无控制台异常。
- [ ] 生成秘密到忽略的runtime私有文件；配置Worker secrets并部署至免费计划可用环境；域名到位后绑定。仅本机显示登录信息，不进Git。
- [ ] 加CI和README/部署说明；运行原有回归和新增测试、publication guard及代码审查。
- [ ] 硬件能够进入下载模式后读取chip/flash信息、保存私有备份，再进行刷写/配网/真实BLE与远程端到端验证。若需要用户按键或导入凭据，继续独立软件工作同时提示所需操作。
